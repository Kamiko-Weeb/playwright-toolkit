# Steal a Brainrot (Roblox)

A complete, publish-ready clone of the **top-earning Roblox meta**: you collect
"brainrot" characters that generate cash on your base, roll for rare/SECRET
ones, and **steal them from other players' bases** — while buying gamepasses to
lock your own base and run faster. All monetization is wired in; you just paste
your IDs.

> Self-contained under `steal-a-brainrot/`. Unrelated to the Python toolkit or
> the simpler `roblox-game/` clicker elsewhere in this repo.

---

## The money loop

1. Spawn on **your base** (8 bases per server, 9 podiums each).
2. Tap **ROLL** to spend cash on a random brainrot — it auto-places on a free
   podium and starts earning **cash/sec**.
3. Rarer units earn *way* more: Common → Rare → Epic → Legendary → Mythic →
   **SECRET**. Each brainrot you own makes your next roll pricier…
4. …so the smart play is to **STEAL**: walk onto a rival's base, hold the
   **Steal** prompt on their brainrot, and it jumps to your base.
5. Buy **Base Lock** so nobody can rob you, **Super Speed** to raid and escape,
   **2x Cash / VIP** to out-earn everyone. Climb the global **Top 10**.

That theft loop is the viral hook — it's why "Steal a Brainrot" hit 150K+
concurrent players.

### Monetization (already built)

| Type | Item | Effect |
|---|---|---|
| Game Pass | **2x Cash** | Double all income |
| Game Pass | **Auto Collect** | Income banks itself, no walking to the pad |
| Game Pass | **Base Lock** | Nobody can steal from you |
| Game Pass | **Super Speed** | Move faster to raid / flee |
| Game Pass | **VIP** | +25% income |
| Dev Product | **10k / 100k / 1M Cash** | Instant cash (repeatable) |
| Dev Product | **Lucky Roll** | Guaranteed Legendary+ brainrot |

Passes = steady baseline. Products (especially **Lucky Roll** and cash packs) =
repeatable whale spending, which is where most of the revenue comes from.

## Setup

### 1. Tools
- [Roblox Studio](https://create.roblox.com/) (free)
- [Rojo](https://rojo.space/): install the **Rojo plugin** from Studio's Plugin
  Marketplace, and the Rojo CLI (`cargo install rojo`, or `rokit install` here
  using the pinned `rokit.toml`).

### 2. Sync into Studio
```bash
cd steal-a-brainrot
rojo serve
```
In Studio: open a **Baseplate**, open the Rojo plugin → **Connect**. Everything
appears — the whole world is generated by code at runtime. Press **Play** and
you can already roll, earn, collect, and (with a 2nd test player) steal.

> **Set Max Players to 8** (Studio → File → Game Settings → so it matches
> `Config.PlotCount` and everyone gets a base). Bump both together to grow servers.

### 3. Enable saving
On create.roblox.com → your experience → **Settings → Security → Enable Studio
Access to API Services**. DataStores (progress saving + the leaderboard) need
this on.

### 4. Publish
`File → Publish to Roblox As…` → new experience → set **Public** when ready.

## Turning on monetization

Create the items on Roblox, then paste their numeric IDs into
[`src/ReplicatedStorage/Shared/Config.lua`](src/ReplicatedStorage/Shared/Config.lua).
Any id left `0` is ignored — no errors, that item just won't sell yet.

- **Game Passes:** experience → *Associated Items → Passes → Create a Pass*.
  Copy the ID from the pass URL, paste into `Config.GamePasses`.
- **Developer Products:** *Associated Items → Developer Products → Create*. Copy
  each ID into `Config.Products`.

```lua
Config.GamePasses = {
    DoubleCash  = { id = 1234567, name = "2x Cash",     desc = "Double all income" },
    AutoCollect = { id = 2345678, name = "Auto Collect", desc = "Bank income automatically" },
    BaseLock    = { id = 3456789, name = "Base Lock",    desc = "Nobody can steal from you" },
    Speed       = { id = 4567890, name = "Super Speed",  desc = "Run faster to steal & escape" },
    VIP         = { id = 5678901, name = "VIP",          desc = "+25% income & a golden glow" },
}
Config.Products = {
    Cash10k   = { id = 111, name = "10,000 Cash",    cash = 10000 },
    Cash100k  = { id = 222, name = "100,000 Cash",   cash = 100000 },
    Cash1m    = { id = 333, name = "1,000,000 Cash", cash = 1000000 },
    LuckyRoll = { id = 444, name = "Lucky Roll",     desc = "Guaranteed Legendary or better" },
}
```

Cashing out Robux → USD requires Roblox Premium + meeting the **DevEx**
requirements (minimum balance, ID-verified eligible-age account). Your own
purchases don't count toward it.

## Swapping in real character models

The brainrots ship as **original placeholder blocks** (a colored body + eyes +
name tag) so you can launch without legal risk. To use real models later, edit
`Plots.makeUnit` in [`src/ServerScriptService/Plots.lua`](src/ServerScriptService/Plots.lua):
clone your model onto the podium instead of building the block, keep the
`Highlight`, `BillboardGui`, and `ProximityPrompt`, and set `PrimaryPart`. The
rest of the economy keys off each unit's `id` / `income` in `Brainrots.lua`, so
nothing else changes.

> Be careful copying the actual meme characters — many are AI-generated with
> unclear ownership, and Roblox moderates stolen assets. Original art is safest.

## Balancing knobs (`Config.lua`)

| Field | Does |
|---|---|
| `PlotCount` / `SlotsPerPlot` | bases per server / podiums per base |
| `BaseRollCost`, `RollCostGrowth` | roll price and how fast it climbs (pushes stealing) |
| `StealHoldSeconds`, `StealRange` | how risky/slow stealing is |
| `Brainrots.List` income + rarity `weight` | the entire earn curve & rarity odds |
| `Multipliers` | what 2x Cash / VIP are worth |

## Realistic expectations

The code is finished. Whether it **earns** is a marketing problem:

1. **Icon + thumbnails** decide ~80% of clicks — copy the front-page brainrot
   games' bright, readable style.
2. **Retention:** ship new brainrots/rarities and events regularly so people
   return. The steal loop already drives sessions.
3. **Discovery:** early traffic usually needs **Sponsored Ads** + friends/creators.
4. **Tune the paywall:** watch what sells and adjust prices.

### Play fair
No misleading "free Robux" claims, no deceptive purchases — follow the
[Roblox Community Standards](https://en.help.roblox.com/hc/en-us/articles/203313410)
and monetization rules. Deceptive monetization is the fastest way to get the
whole game deleted.
